# 信易科技产品线：快期 vs 天勤

本文整理信易科技（Shinny Tech）两条产品线的版本差异、适用范围，以及它们与 iTrader 客户端的关系。

调研时间：2026-10-27。信息来源以官方文档与官方产品页为主，文末列出来源；非官方来源（信易知乎号公告）单独标注。

---

## 1. 一句话结论

快期和天勤是**同一家公司的两条产品线**：快期是面向人操作的 PC/移动客户端，天勤（TqSdk）是面向程序的 Python SDK。两者共用同一个「快期账号」体系。

关键澄清：**「免费版」这个概念只存在于天勤，不存在于快期。** 快期的免费/收费区分的是「能登录哪些期货公司」，不是「能交易哪些品种」。

## 2. 快期产品线比较

| 产品 | 定位 | 适用人群 | 收费 | 平台 |
|---|---|---|---|---|
| **快期2** | 高性能下单终端，直连柜台架构，毫秒级响应；首创自动开平、数据本地实时计算 | 手工交易、手工高频、公司下单交易员 | 免费（单公司版） | Windows |
| **快期3** | 图表化交易终端，支持多屏扩展、K线画线、画线下单、拖线止盈止损、自定义套利 | 进阶交易者、图表交易员 | 免费（单公司版） | Windows（Win10 64 位） |
| **快期专业版** | 程序化交易者的多账户监控终端，支持 CTP / CTPmini / 易盛 v10 / 大连 Xone / 融航 / 杰宜斯等多柜台；内置 Grafana 持仓监控 | 私募、做市商、程序化用户、专业个人 | **收费**，注册快期账号后 15 天免费试用 | Windows |
| **快期 APP** | 移动端行情 + 交易，支持添加多个模拟账户 | 日常盯盘 | 免费 | iOS / Android |

### 2.1 快期「免费版」的真实含义

快期专业版官方手册明确分为两个版本：

| 版本 | 来源 | 收费 | 限制 |
|---|---|---|---|
| **全期货公司版本** | 信易科技官网 | 收费产品，注册后 15 天免费试用 | 无公司限制 |
| **单期货公司版本** | 期货公司官网提供 | 免费 | 只能登录同一家期货公司的账号 |

所以日常说的「快期免费版」实际指**单期货公司版本**——限制在「只能用哪家的账户」，而**品种不受版本限制**，取决于该期货公司给你的账户权限（原油、特定品种、期权等仍需单独申请交易权限）。

这一条是对官方手册的合理推论：官方只声明了公司限制，未声明品种限制。

## 3. 天勤（TqSdk）版本比较

| 维度 | 免费版 | 专业版 | 企业版 |
|---|---|---|---|
| 年费 | 0 | 14888 元/年 | 30000 元/年 |
| 实盘期货公司 | **仅 3 家**：宏源期货、徽商期货、银河期货 | 100+ 家（官方名单见「天勤支持的期货公司列表」） | 同专业版 |
| 绑定实盘账户数 | 3 个 | 3 个（更多需联系工作人员批量购买） | — |
| 回测次数 | 不限（2025 年起取消每日 3 次限制） | 不限 | 不限 |
| 期货 / 期权行情 | 全部期货、商品期权、中金所期权 | 同左 | 同左 |
| 指数行情 | 上证50、沪深300、中证500、中证1000 | 同左 + A股股票实时与历史行情 | 同左 |
| 股票模拟交易 | 无 | 有（`TqKqStock`） | 有 |
| 历史数据下载 | 无 | 有（`DataDownloader`，tick 精度 + 任意 kline 周期） | 有 |
| 行情服务器稳定性 | 标准 | 更稳定（免费版全量升级验证后才升级专业版服务器） | 同专业版 |
| 客服支持 | 社区 | 1v1 讨论组，工作时间内优先响应 | 更高规格 |

### 3.1 天勤免费版真正的限制

官方原话：「对于 TqSdk 免费版，用户只能选择指定的期货公司进行免费实盘交易，专业版支持用户选择其他的期货公司来进行交易。」

**限制的维度是「期货公司」，不是「品种」。** 免费版本身就提供全部期货、商品期权、中金所期权的行情，实盘品种范围与专业版一致。

### 3.2 2025 年的政策放宽（非官方文档来源）

信易知乎号 2025-06 发布公告，称以下能力已对免费用户开放：

- 回测免费，取消每日 3 次限制
- 多账户功能免费（可同时登录 3 个 SimNow 账号；快期模拟账户可用 `TqKq(number=N)` 指定 001~099）
- 期权交易、ETF 期权交易、自定义套利等实盘功能向合作期货公司客户免费开放
- 「获取交易状态」「获取持仓排名」等重点函数免费

该公告**不是官方文档**，落地前建议以个人中心的实际权限为准，或实测对应 API 是否放行。

## 4. 两者的关系

| 关系维度 | 说明 |
|---|---|
| **账号体系** | 天勤没有独立账号，鉴权直接复用快期账号：`TqAuth(快期账号, 密码)` |
| **模拟账户互通** | `TqKq()` 创建的快期模拟账户可在快期专业版、快期 APP、天勤之间任意登录，各账户数据相互独立 |
| **专业版是套餐** | 购买天勤专业版不只得到 SDK 功能，**同时包含一份等时长的快期专业版客户端使用权限**（官方明写） |
| **能力互补** | 策略用天勤写并自动执行，盯盘 / 手动补单 / 多账户风控用快期客户端，二者不是竞争关系 |

iTrader 正是这个组合模式：程序端通过 TqSdk 执行调仓，用户可用快期客户端查看同一个模拟账户的持仓与成交。

## 5. 对 iTrader 客户端的实际影响

### 5.1 现有实现

期货公司分组在双端壳里各维护一份（Qt 版已移除）：

- `shell/Sources/iTrader/AccountViews.swift:4-6`（mac）
- `shell-windows/Views/AccountCard.xaml.cs:23-24`（Windows）

两处均为 `BROKER_GROUPS` 的「天勤免费版 / 天勤专业版」分组，判断正确。实盘账户最终由
`src/infrastructure/trading/tqsdk_executor.py` 以 `TqAccount(broker, ...)` 建会话，候选名单来自上述常量。

已有的用户说明文案：`shell/Sources/iTrader/DashboardView.swift:93` 与
`shell-windows/Views/DashboardPage.xaml.cs:57` 的「常见问题」卡片已解释免费版/专业版差异，
双端文案需逐字一致。

### 5.2 需要注意的点

| 位置 | 现状 | 说明 |
|---|---|---|
| `shell/Sources/iTrader/AccountViews.swift:6`、`shell-windows/Views/AccountCard.xaml.cs:24` | 「天勤专业版」组仅列了 3 家示例（东方汇金、光大期货、国泰君安） | 专业版实际可选 100+ 家。若允许用户自由填写，UI 上应说明该列表只是示例而非全集 |
| `src/domain/entities.py:26`、`src/infrastructure/trading/tqsdk_executor.py:184`、`:292` | 注释称「快期多模拟账户需专业版，暂不支持」 | 2025 年公告称多账户已免费。该前提可能已变化，但公告非官方文档，扩展前应先实测 `TqKq(number=1)` 对免费账号是否放行 |

### 5.3 品种范围结论

iTrader 订阅什么品种由服务器品种库决定，与天勤免费版/专业版无关。真正的品种上限来自两层：

1. **期货公司账户的交易所权限**（原油、特定品种、期权等需额外申请）
2. **柜台系统支持范围**（个别小众柜台可能覆盖不全）

因此客户端不需要针对「免费版」做品种白名单，只需要保证期货公司在可选名单内、账户本身开了对应品种权限。
