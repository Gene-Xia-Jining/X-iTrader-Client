iTrader 智能交易系统 —— Windows 客户端
========================================

一、首次使用
----------------------------------------
1. 解压本压缩包到任意目录（不要放在 C:\Program Files 等受保护目录，
   否则自动更新可能因权限失败）。
2. 双击【安装运行环境.cmd】，它会自动检测并安装缺失的运行环境，
   完成后自动启动 iTrader。
3. 之后日常使用直接双击【X-iTrader.exe】即可。

如果直接双击 X-iTrader.exe 出现"没有任何反应"，说明本机缺少运行环境，
请改双击【安装运行环境.cmd】。这是"框架依赖"发行版的固有行为：
缺 .NET 8 时程序进程无法启动，也就无法自行提示。

二、运行环境要求
----------------------------------------
本程序不自带以下两个运行环境，需要本机安装（脚本会自动装）：

  1. .NET 8 Desktop Runtime (x64)
     https://dotnet.microsoft.com/download/dotnet/8.0
  2. Windows App Runtime 1.6 (x64)
     https://aka.ms/windowsappsdk/1.6/latest/windowsappruntimeinstall-x64.exe

系统要求：Windows 10 1809 (build 17763) 或更高，64 位。

三、目录说明
----------------------------------------
  X-iTrader.exe            主程序（壳），双击入口
  X-iTrader-Backend.exe    本地后端（交易逻辑与行情连接）
  _internal\               后端依赖（含业务代码 src\）
  安装运行环境.cmd         首次使用的运行环境引导脚本
  README.txt               本文件

业务数据（配置、账户、Token、日志数据库）不在程序目录，而位于：

  %USERPROFILE%\.X-iTrader-Client\data\

因此升级或更换程序目录不会丢失数据。

四、自动更新
----------------------------------------
程序启动后可在【设置】页检查更新。更新有两种：

  * 差量更新：仅业务代码变化时，只替换 _internal\src\ 目录，体积很小。
  * 完整更新：程序结构变化时，替换整个程序目录。

已知限制：完整更新会重启程序；若更新失败，关闭 iTrader 后手动重新解压
新版本压缩包到原目录即可（数据仍在 %USERPROFILE%\.X-iTrader-Client\）。

五、常见问题
----------------------------------------
Q: 双击 exe 没反应？
A: 缺少运行环境。双击【安装运行环境.cmd】。

Q: 提示"Windows 已保护你的电脑"（SmartScreen）？
A: 点"更多信息"→"仍要运行"。本程序未做代码签名。

Q: 杀毒软件报毒？
A: PyInstaller 打包的程序常被误报。本程序为内部交易工具，
   可将整个目录加入白名单。

Q: 托盘图标怎么用？
A: 关闭窗口后程序仍在托盘运行（后端常驻）。右键托盘图标可
   "显示窗口""退出后端""退出"。
